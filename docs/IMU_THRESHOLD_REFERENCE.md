# IMU 挥拍检测阈值参考

## 文献来源

### 1. BadminSense 论文 (taizhouchen/BadminSense_Dataset)
- **数据采样率**: 100Hz
- **传感器**: 加速度计 + 陀螺仪 + 磁力计
- **击球类型**: 4种 (BackhandTransition, ForehandHigh, ForehandLob, ForehandKill)
- **数据格式**: xyz + timestamp

### 2. 相关研究综述

#### 羽毛球挥拍特征 (基于文献综合)

| 击球类型 | 加速度峰值 (m/s²) | 角速度峰值 (°/s) | 挥拍时长 (ms) | 主要方向 |
|---------|-------------------|------------------|--------------|---------|
| 高远球 (Clear) | 10-20 | 150-300 | 200-400 | 上方 |
| 杀球 (Smash) | 20-40 | 300-600 | 100-200 | 下方 |
| 平抽 (Drive) | 8-15 | 100-200 | 150-250 | 水平 |
| 挑球 (Lob) | 8-15 | 80-150 | 200-350 | 上方 |
| 吊球 (Drop) | 5-12 | 60-120 | 150-300 | 下方 |
| 发球 (Serve) | 10-18 | 120-250 | 250-400 | 上方 |

#### 重力加速度参考
- 静止状态: ~9.8 m/s² (z轴)
- 挥拍峰值: 可达 3-4g (30-40 m/s²)

### 3. 传感器位置影响

| 传感器位置 | 加速度特征 | 角速度特征 |
|-----------|-----------|-----------|
| 手腕 | 峰值高，噪声大 | 峰值高，反映手腕动作 |
| 前臂 | 峰值中等，较稳定 | 峰值中等，反映前臂旋转 |
| 上臂 | 峰值较低 | 峰值较低，反映肩部动作 |

### 4. 检测算法参考

#### 阈值检测法
```
挥拍开始: accelMagnitude > threshold_low (约 12-15 m/s²)
击球瞬间: gyroMagnitude > threshold_high (约 200-300 °/s)
挥拍结束: accelMagnitude < threshold_low 且持续 > 50ms
```

#### 峰值检测法
```
1. 计算滑动窗口内的加速度幅值
2. 检测局部峰值
3. 峰值超过阈值且前后有明显上升/下降 → 挥拍
```

### 5. 实际测量建议

#### 校准步骤
1. 静止校准: 记录 10 秒静止数据，计算零偏
2. 重力补偿: 减去重力加速度分量
3. 阈值标定: 用已知动作标定阈值

#### 影响因素
- 选手力量: 力量大的选手峰值更高
- 球拍重量: 重球拍可能导致更高峰值
- 击球位置: 高点击球 vs 低点击球
- 运动水平: 专业选手动作更规范
